# FocusDesktop frontend

React and TypeScript application scaffolded with Vite. The backend remains the
source of truth for session state; timer controls and API integration are
implemented in later stories.

Requires Node.js `^20.19.0` or `>=22.12.0`.

## Development

```sh
npm install
npm run dev
```

## Build and lint

```sh
npm run build
npm run lint
```
